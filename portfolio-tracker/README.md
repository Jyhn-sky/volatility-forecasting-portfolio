# Live Portfolio Tracker & Dashboard

A Google Sheets tracker for a mock portfolio of 5–10 stocks. It pulls live
and historical prices with `GOOGLEFINANCE`, logs the thesis behind every
buy and sell, and measures performance against a benchmark (S&P 500 by
default, or the S&P/TSX).

The point is to show ongoing discipline: every position has a written
reason, a catalyst, a key risk and an exit trigger, and the numbers show
honestly whether those decisions beat the market.

## What's in the workbook

| Tab | What it does |
|---|---|
| **Dashboard** | Portfolio value, total and excess return, **alpha** (Jensen's, annualized), **beta**, correlation, volatility, Sharpe ratio, **max and current drawdown**, **sector allocation**, plus charts (growth of 100 vs benchmark, drawdown, sector pie) |
| **Holdings** | Each position with live price, day change, shares, average cost, market value, weight, unrealized P/L and stock beta |
| **Trades** | The decision journal: date, ticker, BUY/SELL, shares, price, fees, **thesis, catalyst, key risk, exit/review trigger** |
| **Settings** | Start date, starting cash, benchmark ticker, risk-free rate |
| **History** | Daily portfolio value rebuilt from the trade log, vs the benchmark, with daily returns and drawdowns |
| **Prices** | Raw daily closes from `GOOGLEFINANCE` |

Yellow cells with blue text are inputs. Everything else is calculated.

## Setup

1. Download `portfolio_tracker.xlsx`.
2. In Google Drive: **New → File upload**, then open it with Google Sheets
   (or in Sheets: **File → Import → Upload → Replace spreadsheet**).
3. Give `GOOGLEFINANCE` a few seconds to load prices.

It only works in Google Sheets. Excel doesn't have `GOOGLEFINANCE`.

## Using it

1. **Settings:** set your start date, starting cash and benchmark
   (`SPY` for the S&P 500, `TSE:XIC` for the S&P/TSX).
2. **Holdings:** put each ticker and its sector in a slot (up to 10).
3. **Trades:** log every buy and sell. The price fills in automatically
   with that day's close; type over it if you have a real fill price.
   Write the thesis *before* you look at how the trade turned out.
4. Check the **Dashboard** weekly and add a review note to the trade log
   when an exit trigger is hit.

The example portfolio (8 stocks across 8 sectors, opened 2026-01-02) and
its theses are placeholders. Replace them with your own picks and reasoning.

## How the metrics are calculated

- **Portfolio value each day** = cash + Σ (shares held that day × closing
  price). Trades are assumed to fill at the close, so buying or selling
  doesn't create a fake jump in returns.
- **Beta** = slope of daily portfolio returns regressed on daily benchmark
  returns.
- **Jensen's alpha** = (avg daily return − rf) − β × (avg benchmark daily
  return − rf), × 252 to annualize.
- **Volatility** = stdev of daily returns × √252. **Sharpe** = (annualized
  return − rf) / volatility.
- **Drawdown** = value / running peak − 1.

## Limitations

- Price returns only; dividends aren't included, so income-heavy stocks
  look slightly worse than they really did.
- `GOOGLEFINANCE` quotes can be delayed up to 20 minutes and occasionally
  fail to load; refreshing the sheet usually fixes it.
- Keep every holding and the benchmark in one currency (all USD or all
  CAD), or the comparison against the benchmark is meaningless.
- Alpha and beta are noisy with only a few months of data. Treat them as
  rough until you have at least 6–12 months of history.

## Rebuilding the workbook

The `.xlsx` is generated by a script, so the layout can be changed in code:

```bash
pip install openpyxl
python build_tracker.py
```
